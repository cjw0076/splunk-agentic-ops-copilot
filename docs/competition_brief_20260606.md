## Tracks

- Observability: anomaly detection, system behavior, operational response.
- Security: threat detection, incident investigation, automated security workflow.
- Platform & Developer Experience: developer workflows, Splunk data/API interaction.

Best fit: Security track plus Best Use of Splunk MCP Server bonus.

## Required Build

Build an AI-powered solution that uses Splunk AI/developer capabilities for real observability, security, or developer productivity problems.

Priority tech signals:

- Splunk MCP Server
- Splunk hosted models
- Splunk developer tools / SDKs / App Inspect
- Splunk data search and investigation workflow

## Submission Surface

Expected assets:

- project built with required developer tools
- selected track
- text description
- demo video under 3 minutes
- install/run reliability on intended platform
- explanation if pre-existing work was significantly updated during the submission period

## Winning Strategy

Build `Security MCP Investigation Copilot`:

- ingest sample logs or synthetic attack timeline into Splunk
- MCP tool calls retrieve events and entities
- agent summarizes root cause, blast radius, timeline, and next actions
- every claim links to Splunk query/event ID
- include feedback form for a shot at bonus feedback prize

## Gates

- Splunk trial/license/developer access.
- MCP server setup.
- No private logs or real customer data in demo.
